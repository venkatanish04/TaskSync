# TaskSync

TaskSync is a fault-tolerant distributed task management
system built using Raft consensus, LSM-Tree storage,
gRPC communication, and Kubernetes.

## Project Goals

- Distributed key-value storage
- LSM-Tree storage engine
- Raft consensus
- gRPC communication
- Concurrent operations
- Fault tolerance
- Docker deployment
- Kubernetes deployment
- Helm
- Prometheus monitoring
- Grafana dashboards
- Fault injection
- Performance benchmarking

## Technology Stack

- Go
- Raft
- LSM-Tree
- gRPC
- Protocol Buffers
- Docker
- Kubernetes
- Helm
- Prometheus
- Grafana
